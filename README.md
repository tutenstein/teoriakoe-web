# teoriakoe-web

Content and promo site for the **Teoriakoe FI** app (iOS and Android). Plain HTML, CSS and
vanilla JavaScript, generated by a small Node build script and hosted on Firebase Hosting.

Site language is Finnish; `/en/` (English) and `/sv/` (Swedish) come in stage 2.

## Requirements

- Node.js 20 or newer (CI uses 22)
- For `npm run sync` only: the app repository next to this one
  (`../traffic-quiz-app/finnish_road_signs`) and Python 3 with `fonttools` and `brotli`

## Commands

```bash
npm install          # marked + html-minifier-terser (+ sharp for sync)
npm run build        # content/ + data/ + templates/ -> dist/
npm run dev          # build, then serve dist/ at http://localhost:8080
npm run check        # quality gate, see below
npm run sync         # refresh data/ and static/ from the app repo
```

`npm run check` fails the build when it finds:

- a page without exactly one `h1`, a `title` over 60 characters, a missing description, canonical, hreflang or breadcrumb JSON-LD
- invalid JSON-LD, images without `alt`/`width`/`height`, duplicate ids
- broken internal links or anchors, external links without `rel="noopener"`
- indexed pages missing from the sitemaps, or `noindex` pages listed in them
- an indexed sign page with fewer than 200 words, CSS over 30 KB
- banned names anywhere in the repo or output, or mentions of AI tooling in page text
- two indexed pages sharing more than 30 % of their sentences (headings, CTA boxes and notices excluded)

## Layout

```
content/
  pages/                 Markdown pages; path = URL (pages/teoriakoe/hinta.md -> /teoriakoe/hinta/)
  liikennemerkit/
    index.md             sign hub text
    ryhmat/<A-I>.md      sign group pages
    merkit/<CODE>.md     long sign texts (e.g. C37.md); a sign without a file gets a noindex page
data/                    copied from the app by `npm run sync` (signs, tips, theory topics only)
static/                  fonts (WOFF2 subsets), images, sign images, store badges
src/css, src/js          one stylesheet; small scripts loaded only where needed
templates/               page templates (plain JS functions returning HTML)
scripts/                 build, dev server, check, sync, font subsetting
```

The question banks of the app are never copied here. `sync.js` takes `signs.json`, `tips.json`
and only the `topics` part of `theory.json`.

## Writing content

Frontmatter (between `---` lines):

| Key | Used for |
|---|---|
| `title` | `<title>`, max 60 characters |
| `description` | meta description, 70–160 characters |
| `h1`, `lead` | page heading and intro line |
| `crumb` | short name in breadcrumbs |
| `published`, `updated` | `YYYY-MM-DD`; `updated` is shown as "Päivitetty" and used as sitemap `lastmod` |
| `sources` | list of `Title \| https://url` lines, shown as "Lähteet" |
| `layout` | `article` (default), `plain`, `quiz`, `home` |
| `disclaimer: true` | shows the independence notice at the top (all pages about the theory test) |
| `ctaTitle`, `ctaText`, `cta: false` | the app box at the end of the page |
| `noindex: true`, `draft: true` | keep a page out of search / out of the build |

Sign texts (`content/liikennemerkit/merkit/C37.md`) also take `summary`, `confused: [C38]`
(drives the "Testaa itsesi" question) and `related: [C38, C39]`. A sign page is indexed only when
its text has at least 200 words; otherwise it is built with `noindex,follow` and left out of the
sitemap. Group F–I pages are expanded in batches of 10–20 the same way.

In Markdown, `[C38](merkki:C38)` links to a sign page. A paragraph that holds only `{{ad}}`
places an ad slot; `{{quiz}}`, `{{search}}`, `{{groups}}` and `{{signs}}` place page components.
A section titled `## Usein kysytyt kysymykset` with `###` questions becomes an accordion and
`FAQPage` JSON-LD.

Test providers change on 1.1.2027: until the end of 2026 Ajovarma runs all theory and driving
tests; from 2027 Traficom's providers differ by town (DEKRA Katsastus, CityKuljettajat, and
Ajovarma for driving tests in Espoo and Helsinki). Pages therefore point readers to Traficom's
list of service locations instead of naming one provider. Review `/teoriakoe/` pages in January 2027.

Facts about the driving licence, the theory test, prices and age limits come only from
traficom.fi, ajovarma.fi and Finlex, and every article lists its sources. Prices always carry
their year. The site never names the source of the app's practice questions, never claims to be
official or approved, and never shows prices of the app ("hinta näkyy sovelluksessa").

## Deployment

`main` deploys to the live site; every pull request gets a Firebase preview channel (14 days)
with its link posted on the PR. Both workflows build and run `npm run check` first.

### One-time setup (owner, in web consoles)

1. **GitHub** – create the private repository `tutenstein/teoriakoe-web` without README or
   .gitignore. Then push this repo (`git remote add origin …` and `git push -u origin main`).
2. **Firebase** – [console.firebase.google.com](https://console.firebase.google.com) → *Add
   project* → name `teoriakoe-web` (Google Analytics off). If the ID is taken, use the suggested
   one and replace `teoriakoe-web` in `.firebaserc` and both workflow files. Then *Build →
   Hosting → Get started* (the CLI steps can be skipped).
3. **Service account for GitHub Actions** – [Google Cloud console](https://console.cloud.google.com)
   with the same project selected → *IAM & Admin → Service accounts → Create service account*
   (`github-deploy`) with the roles *Firebase Hosting Admin*, *Firebase Authentication Admin*,
   *API Keys Viewer* and *Cloud Run Viewer* → *Keys → Add key → JSON*. In GitHub: *Settings →
   Secrets and variables → Actions → New repository secret* named `FIREBASE_SERVICE_ACCOUNT`,
   paste the whole JSON file, then delete the downloaded file. The key never goes into the repo.
4. **Custom domain** – Firebase console → *Hosting → Add custom domain* → `teoriakoefi.fi`, then
   again `www.teoriakoefi.fi` with "redirect to teoriakoefi.fi". Firebase shows a **TXT** record
   (ownership) and **A** records; add them in the DNS settings of the domain registrar. SSL is
   issued automatically once DNS has propagated (from minutes to a day).
5. **Search Console** – [search.google.com/search-console](https://search.google.com/search-console)
   → *Add property → Domain* → `teoriakoefi.fi` → add the TXT record it shows at the registrar →
   *Verify*. Then *Sitemaps* → `https://teoriakoefi.fi/sitemap.xml`.

The default `teoriakoe-web.web.app` address serves the same pages; every page has a canonical URL
on `teoriakoefi.fi`, so search engines index the domain.

Local check of the Firebase config: `npx firebase-tools serve --only hosting` after a build.

### Analytics

None at launch: no trackers and no cookies, so no cookie banner. If visit counts are wanted,
add Cloudflare Web Analytics (cookieless) and extend the CSP in `firebase.json`. GA4 and a
Google-certified CMP only come with AdSense.
